# Retail Sales SQL Analysis

## 📊 Project Overview

This project performs a SQL-driven analysis of a retail sales dataset using **Python, Pandas, and SQLite**. The goal is to answer real-world business questions related to sales performance, customers, products, categories, and monthly revenue trends.

The analysis is performed in a **Jupyter Notebook**, where the dataset is loaded into a SQLite database and analyzed using SQL queries.

## 🎯 Objectives

* Analyze overall retail sales performance
* Identify the highest-revenue product categories
* Find top-performing products and customers
* Analyze monthly revenue trends
* Calculate month-over-month revenue changes
* Compare product performance using ranking
* Analyze sales performance across cities
* Demonstrate SQL concepts used in business analytics

## 🛠️ Technologies Used

* **Python**
* **Pandas**
* **SQLite**
* **SQL**
* **Jupyter Notebook**

## 📁 Project Files

| File                          | Description                                       |
| ----------------------------- | ------------------------------------------------- |
| `Retail_Sales_Analysis.ipynb` | Jupyter Notebook containing the complete analysis |

## 🔍 SQL Concepts Used

The project demonstrates:

* `SELECT`
* `WHERE`
* `GROUP BY`
* `ORDER BY`
* `SUM()`
* `AVG()`
* `COUNT()`
* `LIMIT`
* `JOIN`
* Common Table Expressions (CTEs)
* `LAG()` window function
* `RANK()` window function
* Date-based analysis

## 📈 Business Questions

The analysis answers questions such as:

1. What is the total revenue?
2. Which category generates the most revenue?
3. What are the top 10 products by revenue?
4. How does revenue change month over month?
5. Which cities generate the most revenue?
6. What is the average order value?
7. Which customers spend the most?
8. How do products rank based on revenue?
9. How does each category perform across different months?
10. Which products sell the highest number of units?

## 🚀 How to Run

1. Download or clone this repository.
2. Open `Retail_Sales_Analysis.ipynb` using Jupyter Notebook or JupyterLab.
3. Make sure `retail_sales.csv` is in the same folder as the notebook.
4. Run the cells in order.
5. The SQLite database will be created automatically.

## 📌 Key Takeaway

This project demonstrates how **SQL can be used with Python and SQLite to transform raw retail data into meaningful business insights**.
